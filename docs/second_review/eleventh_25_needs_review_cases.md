## What this pass teaches

- H4 around tags 136-150 has a strong systematic 2019/2020 alignment problem. Many early DBHs are not just noisy; they are biologically incompatible with stable 2021 onward trajectories.
- Similar early-regime problems also appear in H1 and H3. We may need a "pre-2021 persistent-regime mismatch" diagnostic that groups neighboring tags/source rows rather than presenting each as an independent tree problem.
- The low-health single-survey death-label rule keeps showing up. H1/252 is another case where an early dead/0 row should be separated from a later plausible death.
- May 2024 isolated DBH outliers remain common, especially low measurements on otherwise stable large trees.
- Some "revivals" are likely not whole-tree revivals: low sprouts, ivy, or marginal tissue should be handled as source-context/human calls rather than automatic zombie logic.

## Suggested rule changes

- Add a source-era/regime diagnostic for repeated 2019-2020 DBH plateaus that become stable but incompatible from 2021 onward, especially within the same plot and neighboring tags.
- Add a grouped-review view for systematic plot/year blocks, starting with H4 tags 136-150.
- Broaden source-note flags with `sprout`, `ivy sprouted`, and `low` as mortality-context notes that should not automatically imply whole-tree alive status.
- Add a dead-tree isolated-outlier rule for one dead DBH value that departs from both earlier and later dead-tree measurements.
