## What this pass teaches

- Mostly repeat classes now: source-era/regime shifts, isolated one-survey DBH outliers, and single-survey mortality errors.
- The source-era/regime issue is especially common in L6/L7 too. It is no longer an H4/H1-only phenomenon.
- Some source-era-looking shifts have structural notes (`horizontal`, `falling over`, `bent`, `girdling`, `elbow`). The grouped diagnostic should attach those notes and avoid auto-correction.
- Several old dead labels are explicitly contradicted by later notes like `Alive (marked dead last year)` or `not dead`. These are high-confidence mortality-label correction candidates.
- Cluster/stem context keeps mattering for one-survey mortality events, especially Morella.

## Suggested rule changes

- Add L6/L7/M1 examples to the stable-incompatible-era grouped diagnostic.
- Add a note-aware subtype for structural measurement context (`horizontal`, `falling`, `bent`, `elbow`, `girdling`) so those cases remain human-readable but lower urgency.
- Add a high-confidence mortality-label rule when later notes explicitly say `marked dead last year`, `not dead`, or similar.
- Treat single-survey death in cluster/Morella cases as uncertain unless confirmed by later dead evidence.
