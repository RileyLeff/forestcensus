## What this pass teaches

- The source-era/regime problem is broader than H4. It appears in H5, H7, L1, and L4 too, often as stable 2019-2020 DBHs followed by a stable but biologically incompatible 2021+ regime.
- H4/152 shows the inverse: 2019-2020 and 2023+ agree, while 2021-2022 are the incompatible regime. The grouped diagnostic should detect "short stable era incompatible with surrounding stable eras," not only "pre-2021 bad."
- Knot/measurement-location notes can explain alternate DBH regimes and should route to measurement context before generic source conflict.
- Low-health or poison-ivy one-survey death labels keep recurring. These should likely become their own rule-assisted mortality class.
- Some DBH drops at death, especially in weak/fallen/dead trees, may be real structural signal and should not be overcorrected.

## Suggested rule changes

- Generalize the source-era diagnostic to identify stable incompatible eras by plot/tag/year block, not only 2019-2020 vs later.
- Add grouped review candidates for H5/H7/L1/L4 early-regime cases in addition to the H4 block.
- Add note-aware routing for `knot`, `below knot`, and measurement-position notes before DBH outlier/regime review.
- Add a low-health/poison-ivy single-survey death-label route for cases like L0/477 and L0/970.
